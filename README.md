# 角色卡2.0 · character-card

从人物参考图或文字设定出发，分析角色定位、外貌和服装，整理完整中文提示词，再以纯文生图制作角色设定卡。

**原图可用于前期分析；生成阶段只提交文字，不传入原图、服装参考图或已有角色卡。**

## 工作流程

1. 输出一句话角色定位。
2. 分别输出结构化外貌与服装描述，说明未展示部分的补全设计。
3. 在聊天中展示可复制的完整中文提示词。
4. 默认立即生成一张角色卡；明确要求只要提示词或分析时，停在指定阶段。
5. 展示实际生成结果与可访问的文件。结果视觉校验仅按用户明确要求启用。

默认角色卡为3:4竖版、中深灰背景：上排正面与45度头像；下排正面及侧面以白色实心圆占位头部，背面保留真实后脑与发型。换装时保持外貌块，替换服装块后仍走纯文生图。

## 安装

复制下面整段给支持自定义 Skills、可联网下载并写入本地文件的 Agent。安装指令会要求它识别当前系统与自身的安装目录。

```text
请帮我安装 GitHub 上的「角色卡2.0」（character-card）Skill。

仓库：https://github.com/youngerweb2026/character-card
Skill 目录：skills/character-card

请先识别当前操作系统和本 Agent 实际支持的用户级 Skills 安装目录，优先使用原生 Skill 安装器；如果安装器不可用或缺少 Python，请根据环境自动改用 Git、macOS/Linux 的 curl/unzip 或 Windows PowerShell 下载，不要仅因缺少 Python 就停止。完整安装 skills/character-card 目录及其全部文件，保留 SKILL.md 和 agents/openai.yaml，不要只复制 SKILL.md。

如果已有同名 Skill，先比较：内容相同则保留，内容不同则备份后更新，不影响其他 Skill。安装完成后核对来源和文件完整性，检查本 Agent 是否能识别，告诉我实际安装位置、调用方法及是否需要重启或重新加载。如果本 Agent 不支持自定义 Skills，请如实说明。

只执行安装，不启动角色分析或图片生成。本 Skill 的流程是：原图分析角色定位、外貌和服装，整理成完整中文提示词后纯文生图，生成阶段不传入任何图片。
```

同一段指令另存于[安装指令.txt](安装指令.txt)。

## 使用

安装后上传人物图，输入「用角色卡2.0制作角色卡」；支持 `$` 调用的环境可使用 `$character-card`。也可分别提供外貌图和服装图，或只提供文字设定。

- 只要文字：`用角色卡2.0分析这张图，只输出外貌、服装和完整提示词，先不要生图。`
- 换装：`保持外貌描述不变，换成我描述的服装，按纯文生图生成角色卡。`
- 校验：`检查这张角色卡是否符合布局、比例和文字设定，先给出问题。`

## 运行环境

技能文件可安装到支持这一格式的 Agent，实际生图还需要运行环境提供文生图工具。本 Skill 在 Codex 中默认使用内置 ImageGen，并调用环境已有的 imagegen Skill；本仓库不打包该系统 Skill。其他 Agent 的工具与调用方式由其实际环境决定；没有图片生成能力时，应说明限制并保留完整提示词，不把安装完成当成图片生成完成。
