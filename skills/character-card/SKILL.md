# 角色卡2.0

目标：从参考图或角色设定信息出发，先展示文字内容，再直接生成角色卡：
1. 一句话「角色定位」
2. 一份结构化的「外貌描述」（脸 + 发型 + 体型）
3. 一份结构化的「服装描述」
4. 一份可直接复制的完整中文角色卡提示词
5. 使用这份完整提示词生成的一张角色卡

默认流程：分析角色定位、外貌与服装（有图时仅在分析阶段看图）→ 展示定位、描述与完整中文提示词 → 仅用提示词纯文生图生成一张角色卡 → 展示图片与可访问的成果。默认不启用生成结果的视觉校验流程，不输出检查清单或校验报告，也不因自主检查而追加局部重绘或重生成；只有用户明确要求校验结果时才启用可选校验流程。

**图片可用于分析角色定位、外貌与服装，生成阶段与原图脱离。** 无论输入是真人照片、概念图还是已有角色卡，完成定位分析及外貌、服装提取后，都只把完整、可独立理解的文字设定交给生图工具；不上传、不附带、不引用原图或已有生成图，不以图生图或图片编辑代替纯文生图。

用户明确说“只要提示词”“只做分析”“先不要生图”等时，按其指定阶段交付。仅讨论或修改本 Skill 时，不启动角色设计或图片生成。

外貌和服装始终分成两块写。以后换装时只替换服装块，外貌块一字不改，这样角色才稳定。

有参考图时，默认把可见的五官、发型、体型与服饰忠实提取为文字，不主动做去原型化、混搭或特征偏移。生成时仅依据这些文字，不要求与原图绑定或保证复刻原人物。只有用户明确要求去原型化或指定改动时，才修改对应部分。参考图未展示的部分可合理补全，并在分析说明中标明哪些是补全设计。

## 第 0 步：判断输入类型

| 类型 | 用户给的东西 | 图片的用途与生成方式 |
|---|---|---|
| A 真人参考 | 网上模特、真人照片 | 看图分析角色定位、外貌与服装；生成时不垫图，只用文字 |
| B 纯文字 | 性别、年龄、气质关键词 | 完善文字设定后纯文生图 |
| C 自己生成的概念图 | Midjourney 等跑出来的原创角色 | 看图分析角色定位、外貌与服装；生成时不垫图，只用文字 |

原则：有图时可结合图片分析角色定位，并忠实提取可见外貌及服装特征；纯文字输入时按定位设计；所有输入类型最终都走纯文生图。用户提供参考图或角色设定并使用本 Skill 时，默认在文字输出后紧接着生成角色卡，无需另问是否生图；用户明确限定只做文字时遵从该限制。

## 第 1 步：一句话定位（只要这一层，不展开性格）

有参考图时，可结合图中的年龄感、造型、服饰、姿态、环境及画风分析角色定位。确认或补齐以下信息，缺了就按最合理的默认值填，并在输出开头标明自己填了哪些；根据画面推定的身份、职业与气质属于创作定位，不把它们说成照片人物的真实信息：
- 性别、年龄段（如 25 岁左右）
- 身份或职业（一个词即可，如 实习记者、退役拳手）
- 3 个气质关键词（如 冷静、利落、有点疏离）
- 画风：写实摄影（默认）/ 风格化

气质关键词只用来指导设计取舍，不写性格小传、不写背景故事。有参考图时，不因气质关键词而主动更换发型、五官或服饰；纯文字输入时再据此设计。

## 第 2 步：外貌描述（按固定字段写）

A 类：逐张分析参考图，按下面字段写。C 类：分析概念图。B 类：根据定位直接设计。

```
【外貌】
年龄感：
脸型：（如 鹅蛋脸偏窄，下颌线清晰）
肤色肤质：（如 冷白皮，皮肤有自然纹理，不磨皮）
眉：（形状、粗细、浓淡、眉峰位置）
眼：（单/双/内双，眼型，眼距，眼尾走向，瞳色）
鼻：（鼻梁高低、鼻头大小、鼻翼宽窄、侧面轮廓）
嘴：（唇形、厚薄、唇峰、嘴角、唇色）
颧骨与下颌：
辨识特征：（1–2 个，如 左眼下一颗小痣、眉尾稍断）
发型：（长度、分缝、刘海、发量、发质、发尾形态、颜色）
体型：（身高感、肩宽、胖瘦、比例）
```

要点：
- 每个字段写具体形态，少用"好看、精致"这种评价词。
- 「辨识特征」字段要写：有参考图时只记录可见特征，未见明确特征就如实注明，不为增加辨识度而新增痣、疤痕或改变五官；纯文字角色可按定位设计。
- 描述鼻梁弧度、下巴前后位置、后脑勺形状等侧面信息，便于45度头像、侧面身体与背面发型保持一致。参考图无法确认的细节标为合理补全，不把推测写成已观察到的事实。

## 第 3 步：去原型化（可选，仅用户明确要求时）

默认跳过本步，不自动混搭不同人物或偏移已提取的五官、发型和服饰文字设定。纯文生图不等于主动去原型化。

只有用户明确要求与原型拉开区别时，才按其指定范围与幅度调整，可使用混搭不同参考或偏移局部特征等方法。保留未要求修改的部分，并说明实际改了哪些字段，不强制增加改动数量。

## 第 4 步：服装描述

有参考图时，默认保留其中可见的服装、配饰、颜色、材质与结构细节；用户明确指定另一张服装参考或要求换装时，才替换对应部分。无参考图时按定位设计。参考图只到半身时，下装和鞋按现有穿搭风格合理补齐，并注明为补全设计。

```
【服装】
外套/上装：（款式、版型、长度、领型、门襟、口袋、袖口）
内搭：
下装：（款式、版型、长度）
鞋：
配饰：（没有就写"无"）
主色：（不超过 3 个）
材质：（如 水洗棉斜纹、粗纺羊毛）
```

要点：
- 细节要写到能数清（几个口袋、几粒扣子），三视图才对得上。
- 有参考图时保留清楚可见的图案、文字与 logo，不为简化而擅自删除或替换，也不新增品牌标识；纯文字设计时优先采用便于保持多视图一致性的简洁细节。
- 将要保留的图案形状、准确文字、logo 外观及位置具体写成文字，不以“按图保留”代替描述；无法辨认的内容在分析说明中如实注明。
- 背面细节单独写一句（如 背部有横向育克拼接线），未展示的背面结构注明为补全设计。

## 第 5 步：拼装角色卡提示词

把下面模板里的【定位】【外貌】【服装】替换成第 1–4 步分析或设计的完整文字。分析记录与生图提示词分开：原图观察依据、不确定性及补全来源保留在聊天说明中；进入提示词时，写成明确、自足的角色定位、外貌与服装设定。不要把“参考图可见”“照片未展示”“按原图保留”“附图人物”等依赖图片的表述带入提示词，也不加入图片路径或附件指代。

```
一张写实风格的角色设定卡，均匀中深灰色背景（#484848），3:4 竖版，影棚柔光，真实摄影质感，皮肤有自然纹理。适度的柔和轮廓光，让头发和深色服装与背景清楚分离。
画面分上下两行，所有格子是同一个人、同一套服装：
上行两格，大尺寸肩部以上头像：左格正面，直视镜头，中性表情；右格为人物向画面右方转约45度的四分之三面头像，两只眼睛均可见，远侧眼略窄，表情与左格一致。
下行三格，完整站立，双臂自然下垂，双脚完整可见：左格正面全身、中格右侧90度侧面全身，这两格都在正常头部位置放置一个白色实心正圆，作为头部占位；右格背面全身，保留真实后脑和完整发型。
两个占位圆大小完全相同，直径接近背面真实头部包含头发的整体高度；圆底与自然长度的短颈衔接，保留完整头部位置与总身高，不采用裁切头部的版式。圆内无五官、头发、文字或阴影，呈平面的白色圆形，不是立体球体，不遮挡肩膀，也不悬浮。
下行以“白圆加身体”“白圆加身体”“真实头部加身体”三套完整轮廓比较比例：三者采用相同展示尺度、相同身高与体型，头顶、肩线、腰线、髋部、膝盖和脚底分别对齐。身体保持自然成年人体比例，不因圆形占位而拉长躯干或双腿，不缩小背面人物。
上下行之间保留足够留白，两个白圆、背面头部和所有双脚均完整显示。
不添加版式文字、标注、额外 logo 或边框；服装图案、文字和 logo 仅按下文明确描述的内容生成。

【定位】……
【外貌】……
【服装】……
```

A、B、C 类均只使用这份完整文字提示词，不附任何图片，不添加要求对照原图保持人物一致的句子。用户明确要求去原型化或局部改动时，将对应要求落实到具体文字字段，并保留其余设定。

## 第 6 步：先输出文字

在当前聊天中按顺序直接展示以下内容，不要只保存到文件或仅提供链接：
1. 定位（标明哪些是默认补的）
2. 【外貌】描述
3. 【服装】描述
4. 参考图未展示部分的补全说明（有补全时）；去原型化改动说明仅在用户明确要求并实际调整时输出
5. 完整提示词（放在代码块里，方便复制）

文字展示后立即执行第 7 步，不在提示词处结束本轮，也不增加一次生图确认。用户明确只要文字时，在指定阶段结束。

## 第 7 步：默认生成角色卡

- 默认使用 Codex 内置 ImageGen，并在执行生图时应用 imagegen Skill；用户明确指定其他可用平台或模型时遵从其选择。
- 仅使用刚刚展示的完整版提示词纯文生图生成一张角色卡，不擅自缩写、替换已展示的人物设定或添加新的创意要求。生成输入只有文字，不含原始照片、概念图、服装参考图或已有角色卡。
- 调用内置 ImageGen 时，同时省略 `referenced_image_paths` 和 `num_last_images_to_include`，不通过任何其他字段或附件机制传入图片。调用其他平台或模型时也使用文生图入口，不上传参考图片。
- 默认沿用模板的3:4比例、中深灰背景、上排正面与45度头像、下排白圆占位的正侧面及真实头部背面布局。
- 工具完成后直接展示生成图片；有本地文件时给出可直接打开的路径。按实际返回状态说明是否生成完成，工具失败时保留完整提示词并简要说明，不把任务提交当成已生成。
- 默认不开展额外的视觉校验、不输出校验结果、不自动返修或追加生成。用户明确指出某处需要修改时，只处理指定改动；明确要求校验时，再启用下方流程。

## 可选：生成结果校验（默认关闭，仅用户明确要求时）

只有用户明确要求“校验结果”“检查这张角色卡”等时，才逐项检查实际生成图并反馈结果：

- 上排正面和45度头像是不是同一个人（鼻梁、下巴、发际线）；右格是否两眼可见，角度是否接近45度
- 下排正面、侧面是否各有一个正常头部大小的白色实心圆，圆底与短颈衔接；背面是否保留真实后脑和完整发型
- 两个占位圆是否等大，是否以背面头部为尺度参照；三个完整轮廓的总身高、肩线、腰线、髋部、膝盖与脚底是否对齐
- 背景是否为均匀中深灰色（参考 #484848），头发和深色服装是否与背景清楚分离
- 五官、发型和服饰是否符合已展示的文字设定，是否出现未经要求的换脸型、改发型、新增痣或替换穿搭；不以复刻原图人物作为验收标准，补全部分是否已在分析说明中标明
- 三视图服装细节是否一致（口袋数、扣子、衣长、裤型、鞋）
- 背面发型和上排正面、45度头像的发型是否对得上
- 有没有新增的版式文字或标注；服装图案、文字与 logo 是否符合提示词中的具体描述
- 手和鞋有没有明显变形

发现不合格项时，说明具体视图、元素及修改建议；只有用户同时要求修复或重新生成时才执行对应返修。局部问题只修改对应视图或元素，不整段重写提示词。

## 换装 / 复用

同一角色换装：外貌块保持原文，只替换服装块，重新拼装完整提示词后纯文生图。已有角色卡或新服装图片仅用于必要的文字分析，不作为生成输入；不附原图或已定稿角色卡。
